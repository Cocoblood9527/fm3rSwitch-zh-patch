# FM3R Switch 中文补丁玩家工具

这是 Front Mission 3 Remake Switch 中文补丁的 Windows x64 玩家工具。

## 下载

请在 [Releases](https://github.com/Cocoblood9527/fm3rSwitch-zh-patch/releases) 下载对应版本的 `FM3R-Patcher-*-windows-x64.zip`，解压后运行 `FM3RPatcher/FM3RPatcher.exe`。

## 使用说明

1. 准备游戏本体和 `1.0.4.1` 更新，或准备已经合并的游戏 `Data` 目录。
2. 按工具提示选择资源，等待工具完成检查。
3. 选择输出位置生成可用于模拟器的中文补丁。

工具在玩家本机处理游戏资源，不会上传 ROM、密钥或 `Data` 文件。生成的补丁包含主菜单底部署名：

```text
重译文字版本：V20261021_1
重译By：B站 yezizhong
```

本版本内置译文来自 [fm3r-zh-csv](https://github.com/Cocoblood9527/fm3r-zh-csv) 的 `V20261021_1` Release `review_all.csv`。
